# Русская вики VenusBlood

Статический сайт. Исходники лежат здесь, готовые страницы собираются в `_site/`. На GitHub сборку выполняет Actions при каждом push в `main`.

```
content/          тексты — всё, что правится руками
  articles/*.md   статьи о мире и сюжете
  news.yaml       лента обновлений на главной
  people.yaml     досье героев Frontier: имя, роль, биография, связи
  profile-chapters.yaml, story-chapters.yaml, walkthrough.yaml, utgard-people.yaml
  series.yaml, episodes.yaml   каталог игр серии и дополнительные эпизоды
data/frontier/    публичный снимок материалов перевода: написания терминов, vndb.txt, игровые таблицы, цитаты
static/           style.css, search.js, art/ — копируются в сайт как есть
src/              генераторы страниц (механика, прохождение Эдды, кампания)
tools/            import_frontier.py, blur_covers.py, portraits.py
build.py          сборка: python build.py → _site/
originals/        неразмытые обложки, в git не попадают
```

## Собрать и посмотреть

Нужны Python 3 и PyYAML (`pip install pyyaml`).

```powershell
python build.py
```

Затем откройте `_site/index.html` в браузере. Все ссылки относительные, сайт работает с диска.

## Добавить статью

Создайте `content/articles/<адрес>.md`. Имя файла станет адресом страницы: `sinmara.md` → `sinmara.html`.

```markdown
---
title: Летучий корабль «Синмара»
category: Флот Утгарда
card: scenes/sinmara-flight
order: 3
---

Анонс: один-два предложения, они же идут в карточку и в поиск.

## Первый раздел

Абзац. Абзацы разделяются пустой строкой.

![Подпись к иллюстрации.](scenes/sinmara-flight)

## Второй раздел

Абзац.
```

- `card` — картинка для карточки, путь внутри `static/art/` без `.webp`.
- `order` — место в списке статей. Без него статья встаёт в конец.
- Иллюстрация `![подпись](путь)` выводится после раздела, в котором стоит.
- Статья сама попадает в поиск, в карточки «Ещё об Иггдрасиле», и в ней автоматически появляются ссылки на героев и термины.

## Новость на главной

Добавьте запись в начало `content/news.yaml`:

```yaml
- date: '2026-11-20'
  kind: Русский перевод
  title: Заголовок
  url: frontier.html
  text: Одно-два предложения.
```

Категория `Релиз перевода` поднимается наверх ленты и выделяется. Для рабочих срезов — `Русский перевод`.

## Обновить словарь и цитаты из перевода

Сборка не читает vn_kit напрямую: всё нужное лежит в `data/frontier/`. После правок глоссария или вычитки обновите снимок:

```powershell
python tools/import_frontier.py
```

Скрипт берёт из vn_kit `vndb.txt`, таблицы карты и названия глав. Из `glossary.yaml` он переносит в `terms.yaml` только написания и пояснения, которые выводятся на страницах. Описания персонажей и рабочие пометки переводчиков туда не попадают. Из вычитки остаются только реплики, процитированные на сайте. Сам глоссарий и полный перевод в репозиторий не попадают.

## Картинки

Иллюстрации берутся из игры и подбираются по содержанию эпизода. Подпись объясняет, что изображено. Выдуманные пейзажи и персонажи не добавляются.

Обложки игр откровенные, поэтому на сайте они размыты. Новую обложку положите в `originals/cover-<slug>.webp`, затем выполните:

```powershell
python tools/blur_covers.py
```

Размытая копия появится в `static/art/`. Оригиналы в git не попадают.

Портреты героев пересобираются из `character.xp3` по координатам игровой функции `charaSet`: `python tools/portraits.py путь/к/character.xp3`. Скрипту нужен vn_kit рядом с вики.

## Публикация

Каждый push в `main` пересобирает сайт. Через 1–2 минуты изменения видны на GitHub Pages. Если сборка упала, ошибка будет на вкладке Actions репозитория.

## Редактура

Для текстов энциклопедии автор и лоровед применяют навык redaktura, включая проход по следам нейротекста.
